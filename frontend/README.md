# ArgusView Frontend

This directory a quick web interface we built for the project, just to intercept the requests from the ESP32-CAM and display the results.

## Overview

The frontend is built with Next.js and provides a simple interface to:

- View the latest captured image from the device
- Listen to audio descriptions generated by the system

## Installation and Development

```bash
# Install dependencies
npm install

# Run the development server
npm run dev
```
